## 3. Highlight Features (Top 5)

### F-072 — Docker Compose Deployments
- Project type جديد: `EProjectType.DockerCompose`
- يقرأ `docker-compose.yml` ويعرف الـ services
- Pipeline steps خاصة: `docker compose build`, `docker compose up -d`
- Service health checks
- Volume management

### F-073 — Kubernetes Deployments
- Helm chart templating
- kubectl integration
- Rolling updates with rollback
- Resource quotas via K8s ResourceQuota
- Cluster connection via kubeconfig (encrypted)

### F-076 — Zero-Downtime DB Migrations
- Expand-Contract pattern
- Phase 1: Add new column/table (no breaking)
- Phase 2: Backfill data
- Phase 3: Switch reads to new schema
- Phase 4: Drop old schema
- يدعم: MySQL, PostgreSQL via gh-ost أو pt-online-schema-change

### F-079 — Monorepo Support
- Detect package manager: pnpm, npm, yarn, lerna, turborepo
- يحدد الـ packages المتأثرة بـ commit (git diff + dependency graph)
- ينشر الـ packages المتأثرة فقط
- Smart caching (turbo cache integration)

### F-084 — E2E Testing (Playwright)
- Playwright runner داخل deployment pipeline
- Headless تلقائي
- Screenshots + videos on failure
- Tests الـ deployments المعلقة قبل promotion
