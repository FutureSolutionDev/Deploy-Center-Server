## 2. Features in Scope

### 🔴 F-034 — Blue-Green Deployments (P0, XL)

**كيف يعمل:**
- مشروع يحتاج: 2 ports (e.g., 3001 blue, 3002 green) + Nginx
- النشر الجديد يذهب لـ idle environment (green لو blue active)
- بعد Health Check ينجح → Nginx upstream switch
- الـ old environment يبقى warm لـ 5 دقائق (للـ rollback السريع)

**Project additions:**
- `DeploymentStrategy` ENUM('standard', 'blue_green', 'canary')
- `BlueGreenConfig` JSON: `{ blue_port, green_port, nginx_config_path }`

**Implementation:**
- Service `Services/BlueGreenService.ts`
- Nginx config templating + reload
- State tracking في DB

**Effort:** 7-8 أيام

---

### 🔴 F-035 — Canary Releases (P0, XL)

**كيف يعمل:**
- النشر الجديد يأخذ نسبة من traffic (5% → 25% → 50% → 100%)
- المستخدم يتحكم في النسبة عبر slider في UI
- في كل خطوة: monitor metrics + manual approval للنسبة التالية

**Project/Deployment additions:**
- `Deployment.CanaryWeight` INT DEFAULT 0
- `Deployment.CanaryStage` ENUM('5%', '25%', '50%', '100%', 'completed')

**Implementation:**
- Nginx with `split_clients` directive
- Cookie-based stickiness
- Auto-advance بناءً على error rate

**Effort:** 7-8 أيام

### 🟡 F-036 — Blue-Green DNS Automation (P1, L)

**المشكلة:** Nginx switch داخلي. للـ multi-server، نحتاج DNS.

**الحل:**
- Cloudflare API: تحديث A record للـ blue/green IPs
- TTL منخفض (60s) قبل deployment لتسريع التبديل
- Health check + automatic rollback عبر DNS revert

**Effort:** 4-5 أيام
