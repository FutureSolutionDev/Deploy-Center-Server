## 3. Vision Statement

v5.0 يحوّل Deploy Center من **منصة self-hosted** إلى **منصة cloud-native متعددة المستأجرين** قابلة للتوسع جغرافياً وتشغيلياً.

**Key Capabilities:**
- **Geographic redundancy**: deploy في US-East, EU-West, Asia في وقت واحد
- **Hybrid cloud**: مشاريع تعمل عبر AWS و Azure و on-prem
- **Plugin ecosystem**: third-party developers يضيفون integrations
- **Compliance-ready**: تقارير ISO 27001 + GDPR + SOC 2

---

## 4. Architecture Changes (v4 → v5)

```
Current (v4.x):
  Single Node.js server → Redis → MySQL → SSH/SFTP to targets

v5.x:
  ┌─ Control Plane (API + UI)
  │   └─ Federated MySQL (read replicas across regions)
  ├─ Worker Plane (Distributed Build Agents)
  │   └─ pulls jobs from Redis Streams
  ├─ Plugin Runtime (Isolated VM2 sandbox)
  └─ Service Mesh (Istio + OpenTelemetry)
```
