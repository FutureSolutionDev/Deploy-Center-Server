## 3. Highlight Features (Top 5)

### F-086 — AI-Driven Rollback Decisions
- Hybrid approach:
  - **Rules:** Health Check fails + error rate spikes + latency > threshold → rollback
  - **ML:** Train على historical deployments → predict failure probability
- Confidence score (0-1)
- Manual override always available

### F-087 — Configuration Drift Detection
- Daily SSH scan: compares server state with last deployment manifest
- Detects: file modifications, new files, deleted files
- Critical paths: package.json, .env, nginx configs
- Alert + diff view + option to "Sync from Server"

### F-088 — SRE Runbooks
- Built-in playbooks for common issues:
  - "High memory usage" → restart service + scale up
  - "Disk full" → cleanup logs + alert
  - "Slow response time" → enable cache + add replicas
- Manual trigger + AI suggestion ("Looks like X, try runbook Y")
- Custom runbooks per project

### F-089 — Dynamic Scaling Rules
- Auto-apply post-deploy:
  - CPU > 70% for 5 min → scale +1
  - CPU < 30% for 15 min → scale -1
- Min/Max bounds per project
- Cool-down period
- Requires K8s or cloud provider (AWS, Azure, GCP)

### F-094 — Anomaly Detection
- Baseline metrics over 7-day window
- Detect: 3-sigma deviations
- Algorithms: Z-score, IQR, optionally Prophet/ARIMA
- Real-time alerts via notifications
