## 3. Highlight Features (Top 5)

### F-051 — Multi-Platform CLI
- Command: `deploy-center deploy <project> --branch=main`
- Auto-complete for bash/zsh/PowerShell
- Stored credentials via OS keychain
- Real-time logs stream في terminal
- Distributed as `npm install -g @deploy-center/cli`

### F-054 — Vault Integration
- HashiCorp Vault أو Azure Key Vault
- Replace local AES-256-GCM للـ enterprise customers
- Dynamic secrets (rotate automatically)
- Audit trail integration

### F-055 — Vulnerability Scanner
- Integrate Snyk أو Trivy CLI
- يُنفذ كـ pipeline step automatic
- Block deploy لو critical vulnerabilities
- Email digest weekly

### F-060 — Code Coverage Gate
- Project setting: `MinCoverageThreshold` (e.g., 70%)
- يفحص coverage report بعد test step
- Block deploy لو أقل
- يدعم: Jest, Vitest, pytest, go test

### F-064 — Cloud Log Archiving
- بعد retention period (F-025)، logs تُرفع لـ S3/R2 بدل الحذف
- Compression: gzip
- Searchable via UI (download from S3)
